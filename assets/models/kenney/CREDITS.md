# โมเดล 3D จาก Kenney (CC0)

โมเดลในโฟลเดอร์นี้มาจากชุดฟรีของ Kenney (www.kenney.nl) สัญญาอนุญาต Creative Commons Zero (CC0)
ใช้ในเกมเชิงพาณิชย์ได้ ไม่ต้องให้เครดิต (แต่ให้เครดิตไว้เพื่อขอบคุณผู้สร้าง) ไฟล์ License.txt ของแต่ละชุดอยู่ในโฟลเดอร์ย่อย

| โฟลเดอร์ | ชุด | ใช้ทำ |
|---|---|---|
| pirate | Pirate Kit | ต้นมะพร้าว หินก้อนใหญ่ กอหญ้า |
| platformer | Platformer Kit | ดอกไม้ เห็ด รั้วไม้ ต้นสน ก้อนหินเล็ก |
| graveyard | Graveyard Kit | ป้ายหลุมศพ เทียน โกศ โลงเก่า ตอไม้ ฟาง กำแพงอิฐ |
| survival | Survival Kit | กองไฟ ถังไม้ ลัง ถังน้ำ ป้ายบอกทาง |
| fantasy-town | Fantasy Town Kit | แผงขายของ เกวียน ก้อนหิน ต้นสน |
| mini-forest | Mini Forest | ต้นสน หินงอกในถ้ำ ก้อนหิน |
| watercraft | Watercraft Kit | เรือพาย |
| cube-pets | Cube Pets | สัตว์เดินเล่น (หมา แมว ลูกเจี๊ยบ หมู วัว ช้าง ลิง กระต่าย นกแก้ว ปู) |
| mini-characters | Mini Characters | ชาวบ้านเดินเล่น |

ภาพสี `Textures/colormap.png` ของชุด pirate, platformer, fantasy-town, mini-forest ถูกเลื่อนสีใบไม้จากเขียวอมฟ้าเป็นเขียวอมเหลืองให้เข้ากับโทนพาสเทลของเกม
โค้ดที่โหลดโมเดล: `maps/props/model_lib.gd` (แปลงวัสดุเป็นแบบการ์ตูนพร้อมเส้นขอบ), สัตว์/ชาวบ้าน: `maps/props/critter.gd`
