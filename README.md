# สำนักปราบผี Online (Ghost Exorcist Online)

MMORPG แนว Ragnarok Online ธีมนักบวชสำนักต่างๆ ปราบผีไทยและเอเชีย สร้างด้วย **Godot 4**

เอกสารออกแบบ: `design/` ในไฟล์โปรเจกต์ (game-concept-v1.md, tech-plan-godot.md)

## สถานะ: M1 ต้นแบบเล่นคนเดียว
- หมู่บ้านวัดป่า + ทุ่งป่าช้า (ภาพวาดด้วยโค้ดชั่วคราว ยังไม่มี sprite จริง)
- คลิกเพื่อเดิน คลิกผีเพื่อโจมตี (แบบ RO)
- ผี 2 ชนิด: ผีกระสือน้อย (ธาตุวิญญาณ, ไม่ดุ) และผีตะเกียง (ธาตุคำสาป, ดุ จะเข้ามาตีเอง)
- ธาตุ: ตีธรรมดาใส่ผีวิญญาณได้ไม่ค่อยเข้า สกิลศักดิ์สิทธิ์แรงกว่า
- สกิล `1` โปรยน้ำมนต์ (ดาเมจรอบตัว), `Q` ใช้ยาหอมสมุนไพร
- EXP, เลเวลอัป, ของดรอป (เดินทับเพื่อเก็บ), ดวงวิญญาณหายาก, ผีเกิดใหม่, สลบแล้วฟื้นที่วัด

## วิธีเล่น
1. ติดตั้ง [Godot 4.3+](https://godotengine.org/download)
2. เปิด Godot → Import → เลือกไฟล์ `project.godot` ในโฟลเดอร์นี้
3. กด F5 (Run)

## โครงสร้าง
```
shared/   ข้อมูลและสูตรที่ client กับ server จะใช้ร่วมกัน (ผี, ไอเทม, ดาเมจ, เลเวล)
client/   ตัวผู้เล่น, ผี, ไอเทมบนพื้น, HUD, ฉากหลัก
maps/     แผนที่
tests/    ทดสอบอัตโนมัติแบบ headless
```
เกมทั้งหมดเดินด้วย `tick(delta)` เพื่อเตรียมย้ายตรรกะไปรันบน zone server ใน M2

## ทดสอบ
```
godot --headless --path . --script res://tests/run_tests.gd
```
